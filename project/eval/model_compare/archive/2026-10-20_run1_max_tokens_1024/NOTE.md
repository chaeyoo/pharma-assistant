# 1차 실행 보관 (2026-10-20, max_tokens=1024)

같은 설정(모델 3종·심판 claude-sonnet-5·runs=1·층 5개)의 첫 실측이다. 보관 사유:

- `max_tokens=1024` 에서 생성 답변 9건(Sonnet 4, Opus 5 — 복합 층 8, 근거 제거 1)이
  `stop_reason=max_tokens` 로 절단됐고, Sonnet·Opus 의 복합 층 핵심어 누락이 그 절단 답변이었다.
  운영값(4096)으로 올려 전체를 재실행했다(상위 디렉터리의 결과가 정본).
- 이 보관본의 집계는 **재채점 후** 값이다: 회피·반박 정규식 확장, 근거 제거 층 누출 제외,
  적대 층 '반박 동반' 정의, 심판 절단 18건 재판정(judge_max_tokens 1024→4096).
  재채점 전 1차 집계(적대 층 전 모델 '순응' 0.4, Haiku 범위 밖 0.5)는 채점 결함이었다 — REPORT (e) 참고.
