## (e) 한계

- 표본이 작다: simple 32문항, complex 12문항, no_evidence 32문항, out_of_scope 8문항, adversarial 5문항, tool_selection 18문항. 1.000 은 '이 표본에서 실패 관측 0'이지 일반화가 아니다(CI 하한을 함께 읽을 것).
- 질문당 모델당 1회 실행 — 생성은 확률적이라 재실행 시 개별 문항 결과가 바뀔 수 있다(`--runs N` 으로 반복 실행해 분산을 볼 수 있다).
- 심판은 claude-sonnet-5 1개의 확률적 판정이며 사람 검토를 대체하지 않는다. 심판 지표는 참고로만 본다.
- 정답 일치의 결정론 지표는 '핵심어 포함'이라는 대리 지표다(정답 문장이 데이터셋에 없어 원문 발췌 gold_answer 를 추가하고 심판으로 보완).
- '회피 정확'은 회피 표현 정규식 + 미확인 수치 부재의 결정론 근사다. 표현이 정규식 밖이면 회피로 안 잡힐 수 있다(레코드의 answer 로 확인 가능).
- no_evidence 층의 '근거 없이 정답 단정'은 모델이 학습 기억으로 코퍼스와 같은 값을 말한 경우다 — 코퍼스는 데모용 가상 수치라 기억이 '우연히' 맞은 것이며, 근거 없는 단정은 운영 규칙 위반이다.
- 샘플링은 각 모델의 API 기본값이다(Haiku 4.5: thinking 없음, Sonnet 5.5/Opus 5.5: adaptive thinking). 지연·비용 차이에는 이 기본값 차이가 포함된다.
- 도구 선택 단계는 1스텝(첫 tool_use)만 본다 — 도구 실행 후 회복·연쇄 호출 능력은 측정하지 않았다. 기대 라벨(`expect`)은 오프라인 결정론 라우터의 계약(단일 도구·고정 인자, 예: within_days=30, 날짜 원문 그대로)이라 '엄격' 열의 불일치 중 일부는 모델 오류가 아니라 라벨 관점 차이다(예: '이번 주' → within_days=7, 날짜 ISO 정규화, 보조 목록 조회 병행). 그래서 '관대' 열(기대 도구 포함·forbidden 없음)을 함께 두었다. forbidden 도구 호출과 도구 미호출(schema_error)은 두 기준 모두에서 실패다.
- 적대 층의 '주입 무순응'은 marker(거짓 값) 부재 **또는** 반박 표현 동반으로 정의했다. 원래 robustness_eval 의 marker 부재 정의는 추출형 오프라인 답변용이라, 생성 모델이 '99일은 근거에 없고 15일이다'처럼 거짓 값을 인용하며 반박하는 정상 답변을 순응으로 오판했다(1차 집계에서 확인). 엄격 정의의 값은 'marker 등장' 열에 참고로 남겼다.
- 근거 제거 층은 코퍼스 상호참조 때문에 정답 문서를 빼도 다른 문서에 핵심어가 전부 남는 문항(누출)이 있다. 그 문항은 '근거 없음'이 아니므로 회피 분모에서 제외하고 개수(n_leaked)를 표에 드러냈다. 누출 문항에서 회피한 것은 과잉 회피일 수 있으나 이 실험은 그것을 점수화하지 않았다.
- 회피·반박 정규식은 1차 실행 결과를 보고 한 차례 확장했다('역할 범위를 벗어납니다', '명시되지 않습니다' 등 정당한 회피가 누락됐었음). 확장은 전 모델에 동일하게 적용됐고, 재채점은 저장된 답변으로 API 재호출 없이 수행했다(`--rescore`).
- 생성 단계는 운영 에이전트 루프가 아니라 고정 컨텍스트 주입이다(검색 질의를 모델이 고르는 운영 경로와 다르다 — 검색 고정을 위한 의도적 선택).
