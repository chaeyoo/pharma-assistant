추천은 "이 작업에서 이 기준으로 이 모델" 형식이며, 근거는 전부 위 (b)·(c) 의 1회 실측(runs=1)이다. 표본이 작아
(생성 층당 5~32문항, 도구 18문항) 모델 간 차이 대부분이 Wilson 95% CI 안에서 겹친다 — 아래 선택은 "통계적으로 우월"이 아니라
"결정론 지표에서 뒤지지 않으면서 비용·지연이 낮다"는 기준의 선택이다.

### 1. 답변 생성(에이전트 루프, `answer`) — **claude-sonnet-5-5**

기준: 정확도·회피·주입 무순응의 결정론 지표에서 최상위 그룹에 들고, 도구를 실제로 호출하며, 그 조건에서 비용·지연이 가장 낮은 모델.

- **정확도·안전성에서 Opus 와 동률.** 단순 핵심어 일치 32/32 (Opus 32/32, Haiku 31/32),
  복합 12/12 (세 모델 동일), 근거 제거 회피 18/18 (Opus 18/18, Haiku 16/18),
  범위 밖 회피 8/8, 주입 무순응 5/5 (세 모델 동일), 출처 표기 전 층 100%.
- **근거 충실도(심판·참고)에서 복합 층 11/12 = Opus 11/12, Haiku 7/12.**
  Haiku 는 근거 2개를 결합하는 긴 답변에서 근거에 없는 부연(목적·이유 설명)을 덧붙이는 경향이 심판 판정에 반복해서 잡혔다((c) 참고).
- **도구 선택(관대 기준) 16/18** — Opus 17/18, Haiku 13/18.
  Haiku 는 도구를 호출해야 할 턴에 텍스트로 되묻기만 한 경우가 2건(schema_error) 있어, "반드시 도구로 조회한 뒤 답한다"는 운영 계약에 구조적 위험이 있다.
  엄격 기준(오프라인 라우터 계약과 완전 일치)은 Opus 14/18 > Haiku 12/18 > Sonnet 10/18 이지만,
  Sonnet 의 엄격 불일치는 대부분 보조 조회(`list_regulation_documents`) 병행 같은 라벨 관점 차이다((e) 참고).
- **비용·지연.** 단순 층 건당 비용 Sonnet 0.00666 USD vs Opus 0.01476 USD (Opus 의 45%), p50 지연 3116 ms vs 5111 ms (61%).
  이 실험 전체(107문항)의 모델 호출 비용은 Haiku 0.367 / Sonnet 0.831 / Opus 1.819 USD.
- **Opus 를 고르지 않은 이유:** 이 표본에서 Opus 가 결정론 지표로 Sonnet 을 앞선 곳은 도구 선택 엄격 기준뿐이고(CI 겹침), 비용은 2.2배·지연은 1.6배다.
  더 어려운 문항(장문 종합, 다단계 도구 연쇄)에서는 결과가 달라질 수 있다 — 이 실험은 그것을 측정하지 않았다.

### 2. 판정·요약처럼 비용 민감한 짧은 작업(`judge`, `summary`) — **claude-haiku-4-5-20251001**

기준: 고정 컨텍스트에서 짧은 구조화 출력을 내는 작업에서 결정론 정확도가 Sonnet 과 동급이고 비용이 가장 낮은 모델.

- 단순 층 핵심어 일치 31/32, gold 의미 일치(심판·참고) 31/32, 범위 밖 회피 8/8, 주입 무순응 5/5 —
  도메인 문맥 이해는 이 표본에서 Sonnet 과 구분되지 않는다.

- **주의:** 이 실험은 판정·요약 작업 자체를 측정하지 않았다. 운영 judge(의미 왜곡 3종 탐지)의 살아있는 성능은 `eval/judge_eval.py`(키 필요)로 따로 재며,
