검증 게이트 답변이 나가기 전 근거 대조에서 경고가 붙은 비율

전체 경고율 warn_rate
—
분모 = 모든 응답. 회피·무클레임 응답이 늘면 품질 변화 없이도 내려간다.
보정 경고율 warn_rate_checked
—
운영에서 보는 값. 분모 = 수치·날짜 클레임이 있던 응답만 — 질문 구성이 바뀌어도 흔들리지 않는다.
집계 대상
—
누적 응답 / 경고 / 클레임 있던 응답

경고 축별 분해 응답 단위 집계 · 한 응답에 같은 축이 여러 번이어도 +1

폐지본 인용·방향 충돌이 오르면 답변 품질 회귀, 미확인 수치가 급증하면 검증기 오탐(alert fatigue) 쪽을 먼저 본다.

근거 출신 라벨 경고는 아니지만 추이를 보는 신호

케이스 서술 유래 from_case
—
규정 근거 대신 사용자가 쓴 케이스 서술에 기대기 시작하면 오른다.
웹 검색 유래 from_web
—
사내 규정이 아니라 인터넷 결과에 기대기 시작하면 오른다.
