RAPV-Assistant

개인정보처리방침

시행일 2026-10-26 · RAPV-Assistant (제약 규제업무 RA·PV 용 AI 어시스턴트, 포트폴리오 데모)

RAPV-Assistant(이하 "서비스")는 Google 계정 로그인을 통해 이용자를 확인합니다. 이 문서는 서비스가 어떤 정보를 받고, 무엇에 쓰며, 얼마나 보관하는지 설명합니다.

1. 수집하는 정보

Google 로그인 시 Google 이 제공하는 기본 프로필 정보(OpenID Connect openid · email · profile 범위)만 받습니다.

항목용도
이메일 주소이용 허용 여부 확인(허용 목록·허용 도메인 대조), 로그인 성공·거부 기록
이름화면에 로그인한 사용자 표시
Google 계정 식별자사용자별 하루 이용 횟수 계산

Google 계정의 비밀번호, 연락처, 캘린더, 드라이브 등 다른 데이터에는 접근하지 않습니다.

2. 이용 목적

  • 로그인한 사용자인지, 이용이 허용된 계정인지 확인
  • 사용자별 하루 질문 횟수 제한(API 비용 보호)
  • 로그인 성공·거부 같은 보안 관련 운영 기록

수집한 정보를 광고, 마케팅, 프로필 분석에 쓰지 않으며 제3자에게 판매하거나 제공하지 않습니다.

3. 보관 기간과 방식

  • 세션: 로그인 상태는 서명된 쿠키(pa_session)에 담겨 이용자의 브라우저에만 보관되며 7일 후 만료됩니다. 로그아웃하면 즉시 삭제됩니다.
  • 이용 횟수: 서버 메모리에 당일(한국 시간 기준) 집계만 두며, 날짜가 바뀌거나 서버가 재시작되면 사라집니다.
  • 운영 로그: 로그인 성공·거부 시 이메일 주소가 서버 로그에 남습니다. 로그는 호스팅 플랫폼(Google Cloud Run)의 기본 보관 기간이 지나면 자동 삭제됩니다.

서비스는 이용자 계정 정보를 별도 데이터베이스에 저장하지 않습니다.

4. 대화 내용의 처리

이용자가 입력한 질문은 답변 생성을 위해 처리됩니다. LLM 모드가 켜진 경우 질문과 이전 대화가 답변 생성을 위해 Anthropic 의 Claude API 로 전송됩니다. 서비스는 대화 내용을 저장하지 않으며, 운영 로그에는 처리 시간과 검증 결과 같은 지표만 남기고 질문 본문은 기록하지 않습니다.

질문에 환자 실명, 연락처, 주민등록번호 같은 개인정보나 회사 기밀을 입력하지 말아 주세요.

5. 이용자의 권리

로그아웃하면 세션이 삭제됩니다. 운영 로그에 남은 로그인 기록의 삭제나 그 밖의 문의는 아래 연락처로 요청하면 처리합니다. Google 계정 설정의 "서드파티 앱 및 서비스"에서 이 서비스의 접근 권한을 언제든 해제할 수 있습니다.

6. 연락처

개인정보 관련 문의: Google 로그인 동의 화면에 표시된 지원 이메일로 연락해 주세요.

7. 변경

이 방침이 바뀌면 이 페이지에 시행일을 갱신해 공지합니다.
